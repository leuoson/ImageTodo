# 设置弹窗功能需求规格

## 概述

将现有的设置按钮功能从简单的语言切换改为触发设置弹窗，该弹窗从应用底部向上滑出，包含语言切换和截图快捷键配置功能。

## 用户故事

### 主要功能

**作为用户，我希望点击设置按钮时能打开一个设置弹窗，这样我就能访问更多的配置选项。**

**验收标准：**
- 点击主工具栏或侧边栏的设置按钮时，弹窗从底部向上滑出
- 弹窗始终在应用内部显示，不会超出应用边界
- 弹窗具有平滑的动画效果
- 可以通过点击外部区域或ESC键关闭弹窗

**作为用户，我希望在设置弹窗中能够切换应用语言，这样我就能使用我偏好的语言。**

**验收标准：**
- 弹窗中包含语言选择器
- 支持中文（zh-CN）和英文（en）切换
- 语言切换立即生效，无需重启应用
- 当前选中的语言有明显的视觉标识

**作为用户，我希望能够设置截图的快捷键，这样我就能快速进行截图操作。**

**验收标准：**
- 弹窗中包含快捷键配置区域
- 能够捕获和显示用户按下的键盘组合
- 支持常见的快捷键组合（Ctrl/Cmd + 字母/数字）
- 快捷键设置能够持久保存
- 快捷键冲突时提供国际化的警告提示
- 所有快捷键相关的提示文本都支持中英文切换

### 技术需求

**作为开发者，我需要集成轻量级的截图库，这样就能为未来的截图功能做好准备。**

**验收标准：**
- 集成html2canvas库用于DOM元素截图
- 库的大小不超过50KB
- 不影响应用的启动性能

**作为开发者，我需要集成全局快捷键支持，这样用户设置的快捷键就能在系统级别生效。**

**验收标准：**
- 集成Tauri的global-shortcut插件
- 快捷键能够在应用失去焦点时仍然工作
- 提供快捷键注册失败的错误处理

## 功能需求

### FR-001: 设置弹窗显示
- 弹窗从应用底部向上滑出，动画时长200ms
- 弹窗背景使用半透明遮罩
- 弹窗内容区域使用与应用一致的卡片样式
- 弹窗最大高度不超过应用高度的70%

### FR-002: 语言切换功能
- 提供中文和英文两种语言选项
- 使用单选按钮或下拉选择器形式
- 语言切换后立即更新界面文本
- 保存语言偏好设置到本地存储

### FR-003: 快捷键配置
- 提供快捷键输入框，显示当前设置的快捷键
- 点击输入框后进入快捷键捕获模式
- 支持Ctrl/Cmd + 字母/数字的组合键
- 显示快捷键设置状态（已设置/未设置）

### FR-004: 弹窗交互
- 点击弹窗外部区域关闭弹窗
- 按ESC键关闭弹窗
- 弹窗内容支持键盘导航
- 关闭动画与打开动画对称

## 非功能需求

### NFR-001: 性能要求
- 弹窗打开/关闭动画流畅，无卡顿
- 新增依赖不增加超过100KB的包大小
- 快捷键响应时间不超过100ms

### NFR-002: 可用性要求
- 弹窗界面与现有应用风格保持一致
- 所有交互元素具有明确的视觉反馈
- 支持键盘无障碍访问
- 错误信息清晰易懂且完全国际化
- **所有用户界面文本、提示信息、错误消息都必须支持中英文切换**

### NFR-003: 兼容性要求
- 支持Windows、macOS、Linux三个平台
- 与现有的Tauri v2架构兼容
- 不破坏现有的语言切换功能

## 约束条件

### 技术约束
- 必须使用React + TypeScript技术栈
- 必须使用Tailwind CSS进行样式设计
- 必须使用Shadcn/ui组件库保持一致性
- 必须使用Radix UI作为无障碍访问基础

### 设计约束
- 弹窗样式必须与现有应用保持一致
- 使用现有的颜色主题和间距规范
- 图标使用Lucide React图标库
- 动画效果与现有侧边栏动画保持一致

### 业务约束
- 不能破坏现有的语言切换功能
- 截图功能暂时只需要准备基础设施
- 必须支持快捷键的持久化存储
- **所有用户可见的文本都必须进行国际化处理（日志除外）**

## 验收测试

### 测试场景1：弹窗基本功能
1. 点击主工具栏设置按钮
2. 验证弹窗从底部滑出
3. 验证弹窗内容正确显示
4. 点击外部区域关闭弹窗
5. 验证弹窗向下滑出消失

### 测试场景2：语言切换
1. 打开设置弹窗
2. 选择不同的语言选项
3. 验证界面文本立即更新
4. 关闭并重新打开应用
5. 验证语言设置被保存

### 测试场景3：快捷键设置
1. 打开设置弹窗
2. 点击快捷键输入框
3. 按下Ctrl+S组合键
4. 验证快捷键被正确捕获和显示
5. 保存设置并验证持久化

### 测试场景4：键盘导航
1. 使用Tab键在弹窗内导航
2. 验证焦点顺序合理
3. 使用ESC键关闭弹窗
4. 验证焦点返回到设置按钮

## 依赖关系

### 外部依赖
- html2canvas: DOM截图功能
- @tauri-apps/plugin-global-shortcut: 全局快捷键支持
- @radix-ui/react-dialog: 弹窗基础组件

### 内部依赖
- 现有的i18n系统需要扩展
- 现有的Button组件
- 现有的样式系统和主题

## 风险评估

### 高风险
- 全局快捷键可能与系统快捷键冲突
- 不同操作系统的快捷键行为差异

### 中风险
- 弹窗动画可能与现有动画冲突
- 新增依赖可能影响包大小

### 低风险
- 语言切换功能相对简单
- UI组件库成熟稳定
